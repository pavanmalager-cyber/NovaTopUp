# NovaTopup

Futuristic static gaming top-up storefront.

## Current version
- QR-code-only payment flow
- No UPI intent/app-launch button
- No external Free Fire/player-data API
- No backend required
- Local UID format validation only
- Animated magnetic headings, hover effects, reveals, glow, tilt and futuristic motion

## Deploy
Upload the contents of this folder to a static host such as GitHub Pages or a Render Static Site. Keep `assets/upi-qr.jpg` in the `assets` folder.

Payment is not independently verified by this static website.

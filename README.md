# NovaTopup

A standalone, responsive gaming top-up storefront UI.

## Payment details configured
- UPI ID: malager@fam
- QR image: assets/upi-qr.jpg
- UPI intent: generic `upi://pay` flow so compatible UPI apps can be selected on Android.

## Important
This is a front-end/demo implementation. UID verification and payment confirmation are simulated.
For real orders, connect an authorized backend and a legitimate payment provider/webhook. Do not claim a payment is successful merely because a customer entered a reference number.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.
